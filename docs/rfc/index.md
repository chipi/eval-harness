# Proposals (RFCs)

An RFC is a **design under discussion**: the problem, the proposed design and its interfaces,
the alternatives, what it would change for a project pinning the harness, and how it would be
tested. It is where a change is argued before anyone builds it. When it is settled, the choice
is recorded as an [ADR](../adr/index.md) and the RFC is marked accepted, with a link to it.

- **Status:** Draft (open for discussion), Accepted (became an ADR), Rejected (with the reason
  kept), or Withdrawn.
- **An RFC can change while it is a draft.** Once accepted or rejected it is kept as written,
  as the record of the argument.
