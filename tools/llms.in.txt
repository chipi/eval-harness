# eval-harness

> A drop-in harness for evaluating AI systems on your own data: freeze a dataset, run a system against it, and decide
> with paired tests whether one system is better than another or only ahead on this sample. The package is in
> `harness/`; this repository also holds worked evals (`examples/`, `research/`), the docs (`docs/`) and the deployment
> of evals.humancopilot.eu (`infra/`).

This file is the agent-facing index of the docs (llmstxt.org). It is generated by `tools/llms_txt.py` from this
template (`tools/llms.in.txt`) and the docs' own titles and status lines; `make llms` writes it and `make llms-check`
fails when it is stale or a link does not resolve. `AGENTS.md` holds the rules for coding agents. Decisions are ADRs,
designs with their alternatives are RFCs, what users need is in PRDs and what they see in UXS; each set has an index
that lists every document with its status.
