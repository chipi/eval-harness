Privacy

This site sets no cookies and has no forms.

Analytics

Page views and clicks on links are counted with a self-hosted instance of Umami. It sets no cookies and stores no personal data. Counts are aggregate: pages, referrers, countries, browsers and devices.

Cloudflare, which delivers this site, also measures visits and page speed with its Web Analytics. It sets no cookies either.

Server logs

The web server records requests (time, page, IP address, browser) to keep the site running and secure. That includes the catalog and its run inspector, which answer from the same server. Searchable logs are deleted after 30 days. Copies on the server are size-capped and overwritten as new requests come in. Logs are not shared.

Documentation

The documentation is hosted on GitHub Pages. GitHub keeps its own request logs under its privacy statement.

Your browser

The light/dark switch remembers your choice in your browser's local storage. It is not a cookie and is never sent anywhere.
